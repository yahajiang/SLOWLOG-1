## 为什么需要定时暂停

LLM API 调用是有成本的。在深夜或其他安静时段，运行 LLM 服务是浪费资源的。定时暂停插件可以自动在指定时间段内暂停 LLM 处理，节省 API 费用。

## 智能暂停

插件的关键特性是「仅暂停 LLM」。它只拦截 LLM 对话请求，而命令、工具和其他插件继续正常工作。这意味着机器人在暂停期间仍然可以响应基本命令，只是不进行 AI 对话。

管理员可以在暂停期间豁免限制，方便进行测试和维护。

## 跨天支持

时间窗口支持跨天配置，比如 23:00 到 08:00 的夜间暂停。插件会自动处理日期边界，确保暂停逻辑正确执行。

## WebUI 仪表板

插件配备了深色主题的 WebUI 仪表板，提供直观的管理界面：

- 24 小时时间线可视化，清晰展示暂停/恢复窗口
- 倒计时显示，距离下次暂停或恢复的剩余时间
- 实时配置编辑，无需重启即可修改设置
- 状态监控，当前是暂停还是运行状态

## 多时区支持

支持 12 以上时区配置，通过 pytz 库实现。无论你在哪个时区，都能正确配置暂停时间。
