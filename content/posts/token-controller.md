## 为什么需要流量控制

LLM API 调用是按 token 计费的。在群聊场景中，如果不加限制，单个群或单个用户可能会消耗大量 token，导致费用失控。Token 流量控制插件提供了细粒度的用量管理能力。

## 多层限流

插件支持三个层级的限流：

**群聊级**：为每个 QQ 群设置独立的每日 token 上限。不同群可以有不同的额度配置。

**用户级**：在群聊内部，可以为每个用户设置独立的每日 token 上限。这防止了单个用户占用过多资源。

**私聊级**：好友私聊有独立的额度配置，与群聊限额互不影响。

## 超限策略

当用量超过限制时，插件支持两种策略：

**停止调用**：直接拦截 LLM 请求，返回超限提示。

**回退模型**：自动切换到配置的低价模型，继续提供服务但使用更经济的方案。这种阶梯式策略可以在控制成本的同时保持服务可用性。

## 可视化统计

Plugin Page 提供了丰富的可视化功能：

- 实时用量进度显示
- 历史趋势柱状图
- 用户排行榜
- 对话明细查看
- 私聊用量统计

## token 节约策略

插件还提供了多种 token 节约策略：

- **触发词限制**：仅通过 @bot 触发 LLM 回复
- **上下文压缩**：限制最大上下文窗口为额度的 0.5%
- **缓存优化**：GPT 和 DeepSeek 的稳定缓存键策略
